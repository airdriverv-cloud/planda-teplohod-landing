# PLANDA · лендинг «Новогодний корпоратив на теплоходе в Москве»

Статический лендинг без сборки и зависимостей: `index.html` + `assets/css/style.css` + `assets/js/app.js`.
Сделан по ТЗ `ny-teplohod/tz-landing.md`.

## Что внутри

- **13 блоков по ТЗ**: hero → цифры → почему теплоход → форматы → что входит → калькулятор → «что важно знать про декабрь» → 3 сценария вечера → как работаем → гарантии → кейсы → FAQ → финальный CTA.
- **Квиз на 5 шагов** (модальное окно): гости → дата → формат → что нужно → контакт. Валидация телефона, экран «спасибо», сохранение лида в `localStorage` (ключ `pnda_leads`).
- **Калькулятор сметы**: гости, часы, будни/пятница-суббота, опции. Считает вилку и разбивку по статьям.
- **SEO**: title/description, Open Graph, микроразметка `Service` и `FAQPage`.
- **Адаптив**: 360 / 768 / 1024 / 1440+, отдельная мобильная кнопка-CTA.
- **Аналитика**: все события уходят в `window.dataLayer` и в CustomEvent `pnda:event` — подключается к Метрике/GA4 одной строкой в `track()`.

## Изображения

Перегенерация: `python gen_landing.py --all` (или `--only hero`) из корня проекта — если локальный ComfyUI запущен на `127.0.0.1:8188`.

## Локальный запуск

```powershell
python -m http.server 8080 --directory .
```
или просто открыть `index.html` в браузере.

## Что подключить перед запуском в рекламу

1. **CRM/почта**: сейчас заявка пишется в `localStorage`. Заменить блок `track('lead', …)` в `app.js` на `fetch('/api/lead', …)` или вебхук.
2. **Метрика**: вставить счётчик перед `</head>` и в `track()` добавить `ym(ID, 'reachGoal', event)`.
3. **Цели**: `quiz_open`, `quiz_step_1…5`, `lead`.
4. **Телефон и реквизиты** — реальные, из карточки PLANDA; при смене номера править в 4 местах (шапка, hero, CTA, подвал).
5. **Политика и согласия** — сейчас ссылки-заглушки `#`, подставить настоящие URL.
6. **Цены** в калькуляторе — константы `CLASSES` и `OPTS` в начале `app.js`.
